Métricas XP y velocidad del proyecto

Explicación de cómo se calcula el avance del dashboard.

Velocidad

Velocidad = puntos terminados / número de iteraciones. En el dashboard se recalcula con los estados de las HU.

Indicadores

  • % de avance del release
  • Puntos terminados
  • Horas ideales ejecutadas
  • Bugs encontrados
  • Último cambio registrado
Desde el dashboard puedes cambiar el estado de una HU y mostrar cómo cambia la velocidad del proyecto en tiempo real.
