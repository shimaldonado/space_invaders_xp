Guía de ejecución del juego

Comandos y pasos para abrir el proyecto Java Space Invaders.

Opción recomendada: IntelliJ IDEA

  1. Abrir la carpeta SpaceInvadersGrupo1-main.
  2. Verificar que el SDK sea Java 17 o Java 21.
  3. Abrir src/Main.java.
  4. Ejecutar con clic derecho → Run Main.

Desde terminal si el proyecto compila simple

cd SpaceInvadersGrupo1-main
javac -encoding UTF-8 -d out $(find src -name "*.java")
java -cp out Main

En Windows PowerShell se recomienda usar IntelliJ si hay rutas con acentos como MúsicaYSonido.
