XP Space Invaders

Guía para pasar HU a Jira y pruebas a TestRail

Paso a paso para que no te confundas al cargar los datos.

Jira — Historias de Usuario

  1. Crear un proyecto tipo Scrum o Kanban llamado Space Invaders XP.
  2. Crear un Epic: Aplicación de metodología XP al juego Space Invaders.
  3. Usar el archivo jira_historias.csv o copiar cada HU desde el dashboard.
  4. Campos recomendados: Summary, Description, Priority, Story Points, Assignee, Labels.
  5. Asignar responsables: Kevin/David como programadores, Diego como tester, Nahomy como PO.

TestRail — Casos de prueba

  1. Crear un proyecto llamado Space Invaders XP.
  2. Crear secciones por HU: HU-01, HU-02, etc.
  3. Importar o copiar el archivo testrail_casos.csv.
  4. Usar References para conectar con Jira: SÍXP-1, SÍXP-2...
  5. Ejecutar pruebas y actualizar resultados: Passed, Failed, Blocked.
Después: vuelve al dashboard, pega la URL base de Jira y TestRail en la sección de integraciones, y los botones abrirán los enlaces externos.
