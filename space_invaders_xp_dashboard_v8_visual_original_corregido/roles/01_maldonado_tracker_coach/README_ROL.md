# Maldonado — Tracker + Coach + Gestor

## Qué realiza
- Medir velocidad del equipo, avance por iteración, bugs y cumplimiento.
- Organizar stand-up meeting, revisión de iteración y retrospectiva.
- Cuidar que se apliquen valores XP: comunicación, simplicidad, feedback, coraje y respeto.
- Mantener la línea de tiempo, la matriz de responsabilidades y la revisión del proyecto.

## Entregables
- Documento de planificación XP
- Velocidad del proyecto
- Línea de tiempo
- Métricas XP
- Evidencia del trabajo
